# Directory Overview

This directory contains the workspace for a Bachelor's degree seminar project focused on **"Interface-Aware Fuzzing on Android."** The project's goal is to produce a written thesis and an oral presentation that explains the evolution of fuzzing techniques for structured interfaces in Android, moving from static analysis of kernel drivers to dynamic analysis of proprietary system services.

The directory is organized as follows:
- `thesis/`: Contains the draft chapters of the seminar thesis in Markdown format.
- `game_plan/`: Contains strategic roadmaps, expansion plans, and presentation outlines.
- `papers/`: Contains reference material and notes on the three core research papers: DIFUZE, FANS, and NASS.
- `humanization/`: Contains specific guidelines and game plans for refining the thesis's tone to sound more like a human researcher and less like an AI.

# Key Files

- `README.md`: Foundational document containing the mentor's instructions, project objectives, and grading criteria.
- `thesis/TOC.md`: The Table of Contents for the thesis, providing a detailed map of the chapters and their technical focus.
- `game_plan/plan.md`: The primary strategic document outlining the narrative arc and technical takeaways for each research paper.
- `humanization/game_plan.md`: A rule-based strategy for stylistic refinement of the thesis text.

# Usage

This directory serves as a collaborative drafting environment.
- **Thesis Development:** Active writing takes place in `thesis/`. Each chapter follows a logical progression: Technical Background -> Kernel-Level (DIFUZE) -> Userspace (FANS) -> Proprietary/Dynamic (NASS) -> Synthesis.
- **Refinement:** The `humanization/` guidelines should be applied to the thesis chapters to ensure a natural academic register.
- **Milestones:** The `game_plan/` documents track progress towards the three mandatory zoom meetings and the final presentation.
