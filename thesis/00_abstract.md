# Abstract

Android remains the most widely deployed mobile operating system, making it a persistent target for exploitation. As Android's baseline security has evolved—through mechanisms such as SELinux and stringent kernel sandboxing—the attack surface has progressively shifted. Exploiting applications or directly attacking the kernel has become increasingly difficult, leading adversaries to target native system services. These services, particularly those executing within proprietary Hardware Abstraction Layers (HALs), serve as critical intermediaries between the physical hardware and the operating system. Compromising a HAL service frequently enables privilege escalation and provides deeper system access.

However, discovering vulnerabilities in these services via automated fuzz testing presents significant challenges. Communication with these services relies on Inter-Process Communication (IPC) mechanisms, such as `ioctl` and Binder, which enforce rigid structural formats on input data. Traditional mutation-based fuzzers, which generate random or slightly mutated byte streams, are typically rejected during the initial parsing phase, preventing exploration of the underlying logic.

This seminar thesis examines the evolution of "interface-aware fuzzing" on Android, a methodology developed to bypass these structural barriers. The thesis traces the progression from early static source code analysis techniques to contemporary dynamic binary instrumentation approaches. The analysis centers on three seminal systems: DIFUZE, which recovered kernel `ioctl` interfaces using LLVM bitcode analysis; FANS, which modeled stateful Binder dependencies by extracting Abstract Syntax Trees (ASTs); and NASS, which targets the proprietary attack surface.

A primary limitation of systems like DIFUZE and FANS is their reliance on source code, creating an "open-source blind spot." The most privileged native services on modern devices are proprietary, closed-source binaries, rendering static analysis ineffective. NASS addresses this limitation by leveraging universal Remote Procedure Call (RPC) design principles. It introduces Deserialization-Guided Interface Extraction (DGIE) to dynamically infer interface definitions without source code access. Furthermore, NASS utilizes Dynamic Binary Instrumentation (DBI) to extract isolated, thread-specific coverage data from complex, multi-threaded system daemons.

By synthesizing the methodologies of these three systems, this thesis demonstrates the necessity of interface awareness in modern fuzzing. Without accurately modeling the expected interface structures, discovering deep memory-corruption vulnerabilities within the proprietary layers of contemporary mobile devices is largely infeasible.
